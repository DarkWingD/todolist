ToDoList — Calendar tab (design mockup)

A new Cal tab: a month grid (like the reference) with a Month/Week toggle, family filter chips, colour-coded pills for tasks, events and birthdays, and a day-detail sheet. Tap days, toggle people, switch Month/Week. This is a design mockup — nothing is wired to the real app yet.

Theme
Appearance
Tap a day · toggle people · Month / Week

Design choices to react to

  • Colour by person (family member), like the reference. Filter chips at top show/hide each person.
  • Events = coloured bars (can span days). Tasks = a dot + title. Birthdays = 🎂 in that person's colour.
  • Week view is a scrollable day-by-day list for the current week.
  • Birthdays live in a yearly Birthdays list; add manually or import a contacts file (vCard/CSV).
  • A 5th bottom tab Cal sits between Lists and Search.
